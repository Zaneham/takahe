ROADMAP
=======

Done
  - SAT-backed equivalence checking via a miter, for bit-level
    designs, falling back to vectors where it cannot encode
  - Negative-edge clocks (VHDL falling_edge) via a clock inverter,
    so RT_DFF stays posedge-only
  - Structural netlist reading (--netlist), sequential structure
    recovery (--seq), cycle simulation of recovered designs
  - Liberty function expressions parsed into truth tables, so
    complex cells (a31o, o221a) are understood not just matched
  - CNF encoding with k-cycle unrolling, plus an in-tree CDCL
    SAT solver
  - TMR radiation hardening (--tmr, --tmr-full)
  - Fault-injection proof (--fi, --fi-comb), where SAT proves that no
    single upset reaches an output rather than sampling faults and
    hoping. Cuts at the flops, assumes replicas that share a D net
    agree, and names every site that gets through
  - Package/import support with typedef enum width propagation
  - FPGA targeting (iCE40 via nextpnr JSON)
  - Combinational equivalence checking (--equiv)
  - VHDL frontend
  - Four ASIC PDKs (SKY130, IHP, GF180, ASAP7)
  - 13 computing paradigms

Near term
  - More SV: procedural for loops through lowering, multi-clock
  - Enum values usable in case items and expressions
  - Wire mp_bblst into the flow so --equiv's SAT path applies to
    ordinary word-level RTL. The miter is in and proves bit-level
    designs; wide operators still fall back to vectors
  - tk_sat.c needs learnt clause deletion. Heap and phase saving
    are in; a 695k-clause instance solves in 16.5s against
    Cadical's 0.8s, and the clause database still grows unbounded
  - Fix dozenal/qsim equivalence checker failures (optimiser bugs)
  - Bit-blast SHL/SHR/SHRA/MUL/PMUX. Everything downstream that wants
    single bits stops at them, so --fi refuses any design with a
    variable shift or a multiplier
  - Run --fi after technology mapping as well as after TMR. Nothing
    reorders TMR today, but --map optimises post-blast, and a merged
    voter is exactly what --fi exists to catch
  - Group replica flops by D-cone shape, not just by a shared D net.
    Covers hardening done by other tools; Takahe's own TMR always
    shares the net, so this costs nothing today

Medium term
  - SV interfaces and modports
  - Memory inference (RAM/ROM from arrays)
  - ABC integration or equivalent for better gate count
  - More FPGA targets (ECP5, Gowin)
  - CI/CD with regression suite

Long term
  - Timing closure loop (STA feeds back into synthesis)
  - Power estimation
  - FPGA bitstream generation (skip nextpnr)
  - TCL scripting interface
